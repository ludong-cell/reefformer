# JSTARS revision experiments

Scripts and result tables behind the analyses added for the IEEE JSTARS submission: LPF attached to other
learned backbones, context-fusion forms after LPF, GBR DLinear/PatchTST/LSTM baselines, threshold-exceedance
verification, buffered leave-one-sector-out evaluation, the OSTIA second-product replication, and the
exploratory ERA5 forcing extension. Every analysis fits its coefficients on the 2018-2021 validation period
only; none uses 2022-2025 or 2026 observations in any fit. Those added after the 2026 holdout had been
accessed are reported as exploratory in the manuscript.

## Layout

- `scripts/` — the scripts exactly as run, plus the helper modules they import.
- `results/` — the result tables (CSV/JSON) the manuscript and its Supplementary Tables S13-S19 are built from.

## Paths

The scripts are archived as run in the research workspace, so they refer to the workspace layout. The
processed datasets they read are byte-identical (same SHA-256) to the files released in `data/processed/`:

| Workspace path used by the scripts | Released file | SHA-256 (first 16) |
|---|---|---|
| `data/frozen_154_ssta_v1/dataset_daily.npz` | `data/processed/hainan_coraltemp_daily.npz` | `1851293fbd1e8a66` |
| `data/gbr_generalization_v1/dataset_daily.npz` | `data/processed/gbr_coraltemp_daily.npz` | `d67c0ed5776c0c0c` |

Per-seed prediction arrays (`*.npy`) are not included because of their size; they are regenerated by the
training scripts. ERA5 inputs are downloaded with `download_era5_arco_region.py` (ECMWF ARCO mirror) or
`download_era5_cds_region.py` (CDS API), both of which read credentials from the user's own `~/.cdsapirc`.
